# Build Roadmap

## Done in This Scaffold

- C++20 core library.
- Streaming archive writer and reader.
- Split `.bin` output.
- Generated `setup.exe` template copy.
- Manifest-based extraction.
- Missing BIN detection.
- CRC and hash validation.
- Resume state for completed files.
- Hardware and disk-space checks.
- Packer and installer executables.
- Qt 6 Quick/QML developer GUI source.
- Qt 6 Quick/QML installer GUI source.
- Optional Qt CMake integration.
